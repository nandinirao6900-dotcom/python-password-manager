# 🔐 Python Password Manager

A beginner-friendly **command-line Password Manager** built with **Python**. This application allows users to securely store, view, search, update, delete, and generate passwords using a JSON file.

---

## ✨ Features

- ➕ Add new passwords
- 👀 View saved passwords
- 🔍 Search passwords by website
- ✏️ Update existing passwords
- 🗑️ Delete passwords
- 🔑 Generate strong random passwords
- 💾 Store passwords in a JSON file
- ⚠️ Handle invalid input and missing files gracefully

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/nandinirao6900-dotcom/python-password-manager.git
```

2. Go into the project folder

```bash
cd python-password-manager
```

3. Run the program

```bash
python password_manager.py
```
